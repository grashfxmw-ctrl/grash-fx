# GRASH FX Website — Clean Build

This folder is the clean website foundation on the `grash-fx-clean-website` branch.

## Current stage
- Responsive GRASH FX landing page and investment-plan cards.
- Plan figures: 10% / $50 minimum, 20% / $500, 30% / $1,000, and 40% / $2,000.
- Seven-day duration displayed for each plan.
- Preview-only login and signup dialogs; they do not create accounts or store data.
- No deposits, withdrawals, balances, authentication, or investment calculations are connected to a backend.

## Next stage
Set up the project architecture and secure authentication/database before wiring any account features. Keep real funds and financial claims out of the website until the business model, risk disclosures, and applicable legal requirements have been reviewed.

The original root-level application and the `main` branch have not been changed by this clean-build work.
